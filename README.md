# נאמן: הגרסה המלאה

מערכת שמחזירה לקוחות לחנויות חיות. כל חנות נרשמת עם אימייל וסיסמה, ומקבלת קישור הרשמה ו-QR משלה, סרטון משלה ונתונים שרק היא רואה.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האפליקציה של בעל החנות: כניסה, פתיחת חנות, היום, רישום מכירה, לקוחות, דוח, עמדת QR, הגדרות |
| `join.html` | דף ההרשמה שהלקוח פותח מה-QR (`join.html?s=שם-החנות`) |
| `js/config.js` | **המקום היחיד שצריך למלא**: כתובת ה-Supabase והמפתח הציבורי |
| `js/core.js` | חישובים משותפים: כמה אוכל ביום, תאריכים, טלפונים |
| `js/smart-trim.js` | העריכה החכמה של הסרטון (רצה בדפדפן, בלי שרת ובלי עלות) |
| `css/app.css` | העיצוב |
| `supabase/schema.sql` | בסיס הנתונים וההרשאות. מריצים פעם אחת |

## התקנה (בערך 15 דקות)

1. **פרויקט Supabase חדש**: ב-supabase.com לוחצים New project. כדאי לבחור אזור Frankfurt.
2. **בסיס הנתונים**: נכנסים ל-SQL Editor ולוחצים New query. מדביקים את כל התוכן של `supabase/schema.sql` ולוחצים Run. אפשר להריץ שוב בלי נזק.
3. **מפתחות**: ב-Project Settings → API מעתיקים את Project URL ואת המפתח `anon public` לקובץ `js/config.js`.
   אסור לשים שם את המפתח `service_role`.
4. **אימייל**: ב-Authentication → URL Configuration מגדירים ב-Site URL את הכתובת שבה האתר יעלה.
   לבדיקות אפשר לכבות זמנית ב-Authentication → Providers → Email את האפשרות Confirm email.
5. **בדיקה במחשב**: פותחים את התיקייה עם שרת מקומי (למשל Live Server ב-VS Code). לא לפתוח את `index.html` בלחיצה כפולה.
6. **העלאה לאוויר**: ריפו חדש ב-GitHub ו-GitHub Pages. **רק כשאתה מחליט.**

## מה כבר עובד

- הרשמה וכניסה לכל חנות, כולל שחזור סיסמה.
- **הפרדה מלאה בין חנויות:** כל חנות רואה רק את הלקוחות שלה. זה נבדק על Postgres: חנות אחת לא רואה ולא יכולה לכתוב לנתונים של חנות אחרת, וגם לא להעלות סרטון לתיקייה שלה.
- **מוצרי ברירת מחדל:** חנות חדשה מקבלת 7 מוצרים מוכנים לעריכה.
- **הרשמה דרך QR:**
  - דף ציבורי שלא חושף שום מידע על לקוחות.
  - בלי סימון אישור לקבלת הודעות אי אפשר להירשם.
  - הגבלה של 60 הרשמות לשעה לכל חנות, נגד הצפה.
- **לקוח שמבקש להסיר את עצמו** לא נמחק אלא מסומן כמי שלא מקבל הודעות, כדי שלא יקבל הודעות שוב בטעות.
- **עמודת `plan`** (סוג המנוי) נשלטת רק על ידך. חנות לא יכולה לשנות אותה לעצמה.
- **סרטון לכל חנות** ב-Storage, עם עריכה חכמה וכפתור לחזרה למקור.

## עוד לא נבנה

- **שליחה אוטומטית בוואטסאפ:** דורשת WhatsApp Business API ושרת. כרגע השליחה היא בלחיצה מהוואטסאפ של החנות.
- **גבייה חודשית מהחנויות** (למשל דרך משולם או Grow).
- **חיבור לקופה או לאתר של החנות.** בינתיים חנות עם אתר יכולה לשים באתר קישור לדף ההרשמה שלה.
